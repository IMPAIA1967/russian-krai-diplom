# Русский Край

**Русский Край** — это современный веб-сервис для ресторана традиционной русской кухни. Проект разработан в качестве дипломной работы и представляет собой полнофункциональную платформу для управления рестораном: от онлайн-бронирования столиков до системы отзывов и управления командой.

## Цели проекта

- Создать удобный интерфейс для бронирования столиков
- Предоставить гостям информацию о меню и команде
- Реализовать систему отзывов с модерацией
- Обеспечить администраторов мощным инструментом управления
- Предоставить REST API для интеграции с мобильными приложениями

##  Возможности

### Для пользователей

- Регистрация и авторизация по телефону или email
- Онлайн-бронирование столиков с выбором даты и времени
- Просмотр меню с фильтрацией по категориям
- Система отзывов с рейтингом (1–5 звёзд)
- Личный кабинет с историей бронирований
- Адаптивный дизайн для мобильных устройств

### Для администраторов

- Управление бронированиями (подтверждение / отмена)
- Модерация отзывов (публикация / удаление)
- Управление командой (добавление / редактирование сотрудников)
- Управление меню (блюда, категории, цены)
- Просмотр статистики посещаемости
- Email-уведомления о новых бронированиях

### API

- RESTful API для всех сущностей
- JWT-аутентификация
- Фильтрация, поиск и сортировка данных
- Пагинация результатов
- Документация в формате OpenAPI

## 🛠Технологии

### Backend

- **Python 3.13** — язык программирования
- **Django 6.0.2** — веб-фреймворк
- **Django REST Framework 3.15** — создание API
- **djangorestframework-simplejwt** — JWT-токены
- **psycopg2-binary** — драйвер PostgreSQL
- **Pillow** — работа с изображениями

### Frontend

- **HTML5** — семантическая разметка
- **CSS3** — стили с анимациями
- **JavaScript (ES6+)** — интерактивность
- **Google Fonts** — шрифты Cormorant Garamond, Montserrat

### База данных

- **PostgreSQL** — основная БД
- **SQLite** — для разработки и тестирования

### DevOps и инструменты

- **Docker** — контейнеризация
- **Docker Compose** — оркестрация
- **Git** — контроль версий
- **pytest** — тестирование
- **flake8** — линтинг кода

##  Быстрый старт

### Клонирование репозитория

```bash
git clone https://github.com/IMPAIA1967/russian-krai-diplom.git
cd russian-krai-diplom
```

```
# Создаём виртуальное окружение
python -m venv .venv

# Активируем (Windows)
.venv\Scripts\activate
# Linux/Mac: source .venv/bin/activate

# Устанавливаем пакеты
pip install -r requirements.txt
```
### Настройка БД и запуск
```
# Применяем миграции
python manage.py migrate

# Создаём суперпользователя
python manage.py createsuperuser

# Запускаем сервер
python manage.py runserver
```

Откройте http://127.0.0.1:8000/ 

### Тестирование
```
# Запустить все тесты
pytest

# С подробным выводом
pytest -v

# С проверкой покрытия
pytest --cov=restaurant

# Линтинг кода
flake8 restaurant/
```

### Docker
```
# Сборка и запуск
docker-compose up --build

# Остановка
docker-compose down

# Логи
docker-compose logs -f
```

##  Ключевые особенности

- **✅ Кастомная модель User** — гибкая система авторизации по телефону или email
- **✅ Бронирование с токенами** — подтверждение бронирования по уникальной ссылке из email-письма
- **✅ Модерация контента** — отзывы и профили сотрудников публикуются только после одобрения администратором
- **✅ Адаптивный UI** — интерфейс идеально работает на мобильных устройствах и десктопах
- **✅ REST API** — полностью готов к интеграции с мобильным приложением
- **✅ Чистая архитектура** — код легко масштабировать и поддерживать благодаря разделению на приложения
