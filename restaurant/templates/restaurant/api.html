API Документация

RESTful API для интеграции с системой ресторана "Русский Край"

GET /api/categories/

Получить список всех категорий меню. Возвращает категории с количеством блюд в каждой.

Пример ответа:
[ { "id": 1, "name": "Закуски", "description": "Холодные и горячие закуски", "order": 1, "menu_items_count": 3 } ]
GET /api/menu/

Получить список всех блюд меню. Поддерживает фильтрацию, поиск и сортировку.

Параметры:
?category=1 - фильтр по категории ?is_available=true - только доступные блюда ?search=борщ - поиск по названию ?ordering=price - сортировка по цене
GET /api/reservations/

Получить список всех бронирований.

POST /api/reservations/

Создать новое бронирование столика.

Пример запроса:
{ "guest_name": "Иван Иванов", "guest_phone": "+79991234567", "guest_email": "ivan@example.com", "reservation_date": "2026-03-01", "reservation_time": "19:00:00", "guests_count": 4, "special_requests": "Столик у окна" }
POST /api/auth/login/

Аутентификация пользователя и получение JWT токенов.

Пример запроса:
{ "email": "admin@russian-krai.ru", "password": "password123" } Ответ: { "refresh": "eyJ0eXAiOiJKV1QiLCJhbGc...", "access": "eyJ0eXAiOiJKV1QiLCJhbGc...", "user": {...} }
POST /api/auth/register/

Регистрация нового пользователя (администратора).
